# Vienna German Tutor

Everyday Viennese German: five rotating daily phrases with cultural notes, a
spaced-repetition flashcard drill, and five roleplay scripts for the situations
you actually hit — the Kaffeehaus, the U-Bahn ticket window, the Magistrat, the
supermarket, and asking directions.

**Use it here:** https://gerryduffy123.github.io/vienna-german-tutor/

Single self-contained HTML file. No build step, no dependencies, no network
requests, no accounts. Works offline — download `index.html` and open it in any
browser. Progress is stored locally in your own browser.
